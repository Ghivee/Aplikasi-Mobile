# Praktikum Aplikasi Mobile

Proyek laporan praktikum mata kuliah Aplikasi Mobile: empat aplikasi Flutter kecil.

[English](README.md)

## Proyek

| Folder | Isi |
| --- | --- |
| `kalkulator_bmi` | Kalkulator BMI |
| `news_app` | Daftar judul berita dari NewsAPI (isi `NEWS_API_KEY` lewat `--dart-define` sebelum menjalankan) |
| `listview_sharedpreferences` | ListView yang disimpan dengan SharedPreferences |
| `id_card_flutter` | Tampilan kartu identitas digital |

Setiap folder adalah proyek Flutter tersendiri: masuk ke foldernya, lalu jalankan `flutter pub get` dan `flutter run`.
