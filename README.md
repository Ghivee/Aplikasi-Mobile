# Mobile Application Coursework

Lab report projects for the Mobile Application course: four small Flutter apps.

[Bahasa Indonesia](README.id.md)

## Projects

| Folder | What it is |
| --- | --- |
| `kalkulator_bmi` | BMI calculator |
| `news_app` | News headline list from NewsAPI (set `NEWS_API_KEY` with `--dart-define` before running) |
| `listview_sharedpreferences` | ListView backed by SharedPreferences |
| `id_card_flutter` | A digital ID card layout |

Each folder is a separate Flutter project: `cd` into it, then run `flutter pub get` and `flutter run`.
